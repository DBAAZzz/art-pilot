# Art Pilot

Art Pilot 是一个基于 Codex 生图能力的 AI 视觉创作桌面工作台：不需要单独配置图片生成 API，需要有 Codex 生图的 Plus、Pro 等会员，就可以生成图片、管理提示词、沉淀素材，并把一次好结果继续变成下一次创作的起点。

它关注的不是“多一个 API 调用入口”，而是把 Codex 生图过程里最容易丢失的东西保存下来：prompt、参考图、生成记录、素材版本和可复用的创作方法。

![创作首页](images/创作首页.png)

## 核心能力

- **Codex 生图**：复用本机 Codex 能力生成图片，不需要额外接入图片 API。
- **提示词模板**：把成熟 prompt 做成可复用模板，支持文本变量和图片变量。
- **素材管理**：自动保存生成图片，支持搜索、收藏、查看详情和打开本地文件。
- **继续创作**：从历史图片一键带回 prompt 和参考图，快速延展风格或生成变体。
- **本地优先**：图片库和创作历史保存在本地，更适合长期沉淀个人或团队资产。

## 使用前提

- 本机已安装并登录 Codex。
- 账号拥有支持图片生成的 Plus、Pro 等会员能力。
- Art Pilot 不要求配置 OpenAI API Key 或第三方图片生成 API。

## Roadmap

- **更强的创作工作流**：任务队列、批量生成、失败重试、多版本对比。
- **更聪明的资产库**：按风格、构图、色彩、项目、模板和参考图关系组织素材。
- **风格与模板体系**：把稳定风格、品牌规范和高质量 prompt 沉淀成可复用资产。
- **项目空间**：围绕品牌、活动、游戏、美术方向或客户项目管理完整创作上下文。
- **AI 创意助理**：基于历史素材主动提出延展方向、系列化方案和优化建议。
- **团队协作**：共享素材库、模板库、风格库和项目经验，让 AI 创作能力在团队内复利增长。
- **多模型编排**：按任务自动组合生成、编辑、扩图、抠图、后处理等能力。

## 开发状态

Art Pilot 仍处于早期开发阶段，当前版本主要用于验证 AI 视觉创作的核心工作流：生成、模板、素材沉淀和继续创作。界面、功能边界和数据结构都还会持续调整。

## 快速开始

```bash
pnpm install
pnpm dev
```

常用命令：

```bash
pnpm typecheck
pnpm build
```

项目使用 pnpm workspace，桌面端应用位于 `apps/desktop`。
