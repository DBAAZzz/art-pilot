# Art Pilot

[English](README.md)

Art Pilot 是一个 macOS 图片创作工作台，用来把 Codex 的图片生成能力变得更适合日常创作：管理提示词模板、沉淀生成结果、整理素材，并从满意的图片继续延展新版本。

![创作首页](images/创作首页.png)

## 下载

安装包已发布在 GitHub Releases：

[下载 Art Pilot](https://github.com/DBAAZzz/art-pilot/releases)

下载最新的 `.dmg` 安装包后，将 `Art Pilot` 拖入 `Applications` 即可使用。

Art Pilot 会调用本机已登录的 Codex，不需要额外配置 OpenAI API Key。首次使用前，请确保本机已安装并登录 Codex CLI。

## 主要功能

- **图片生成**：在桌面端使用 Codex 生成图片。
- **提示词模板**：保存常用提示词，支持文本变量和图片变量。
- **素材管理**：集中管理生成结果、收藏图片和本地文件。
- **继续创作**：从历史图片带回提示词和参考图，快速生成变体。
- **本地保存**：图片和创作记录保存在你的电脑上。

## 使用提示

- 如果 macOS 拦截首次打开，请到 `系统设置 -> 隐私与安全` 中选择“仍要打开”。
- 如果应用提示 Codex 环境异常，可以在 `设置 -> 环境检测` 中查看安装、登录和版本状态。
- 图片库位置可以在 `设置 -> 数据存储` 中修改。
