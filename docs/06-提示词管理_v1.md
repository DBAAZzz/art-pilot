# 提示词管理 v1 方案

## 背景

当前 `提示词管理` 页面还是占位页，但产品上已经明确需要维护生图提示词，并支持从 YouMind 这类提示词详情页导入单条提示词。

已经验证 YouMind 的单条详情页可以直接读取到结构化内容。例如：

```txt
https://youmind.com/zh-CN/prompts/momotaro-irasutoya-hybrid-slide-13983
```

页面中可读取字段包括标题、描述、完整 prompt、作者、发布时间、原始语言、分类、预览图和原始来源链接。

v1 的重点不是批量抓取提示词库，而是先打通单条提示词维护闭环：

```txt
YouMind 详情页 URL
  -> 主进程抓取并解析
  -> renderer 展示导入预览
  -> 用户确认保存
  -> SQLite 持久化
  -> 提示词管理页列表展示
```

## 目标

- 用户可以粘贴 YouMind 单条提示词详情页 URL。
- 应用可以抓取该页面并解析出提示词内容和基础元数据。
- 前端可以展示导入预览，包括提示词正文、标题、来源、分类和预览图。
- 用户确认后，提示词保存到主进程 SQLite 数据库。
- 提示词管理页可以展示已保存提示词列表。
- renderer 不直接抓网页、不直接访问 Node.js 或 SQLite。
- 后续可以扩展编辑、搜索、标签、复制到创作页和批量导入。

## 非目标

- 不做 YouMind 列表页批量导入。
- 不做全站爬取、分页加载或定时同步。
- 不做账号登录、收藏同步或 YouMind 私有内容读取。
- 不在 v1 下载或缓存远程预览图到本地。
- 不做复杂提示词编辑器。
- 不做多来源通用解析框架；v1 只把 YouMind 详情页解析做好。

## 核心决策

提示词抓取和保存都放在 Electron main process。

```txt
Renderer
  -> preload bridge
  -> PromptController
  -> PromptImportService / PromptService
  -> SQLite
```

原因：

- 抓网页需要网络请求和 HTML 解析，放在主进程更符合现有边界。
- SQLite 只应由主进程访问，renderer 只通过受控 IPC 读写。
- YouMind 页面结构变化时，只需要调整 `PromptImportService`，不影响 UI 和数据库服务。
- 保存前预览和最终保存复用同一个导入草稿结构，避免前后字段不一致。

## 推荐交互

提示词管理页第一版采用左右两栏或上下分区：

```txt
顶部：URL 输入框 + “读取提示词”按钮

左侧 / 上方：
  导入预览
  - 标题
  - prompt 正文
  - 描述
  - 分类
  - 来源信息
  - 预览图
  - “保存”按钮

右侧 / 下方：
  已保存提示词列表
  - 标题
  - prompt 摘要
  - 分类
  - 来源站点
  - 更新时间
```

流程：

1. 用户输入 YouMind 详情页 URL。
2. 点击“读取提示词”。
3. renderer 调用 `window.api.previewPromptImport(url)`。
4. 主进程 fetch 页面并解析为 `PromptImportDraft`。
5. renderer 展示导入预览。
6. 用户点击“保存”。
7. renderer 调用 `window.api.savePrompt(draft)`。
8. 主进程写入 SQLite。
9. renderer 重新调用 `window.api.listPrompts()` 刷新列表。

## 数据模型

### Prompt

建议在 `packages/shared/src/prompt.ts` 新增共享类型：

```ts
export type PromptSourceSite = 'youmind' | 'manual'

export type PromptPreviewImage = {
  url: string
  alt?: string
}

export type PromptRecord = {
  id: string
  title: string
  content: string
  description?: string
  sourceSite: PromptSourceSite
  sourceUrl?: string
  sourceAuthor?: string
  originalSourceUrl?: string
  originalLanguage?: string
  categories: string[]
  previewImages: PromptPreviewImage[]
  createdAt: number
  updatedAt: number
}

export type PromptImportDraft = Omit<PromptRecord, 'id' | 'createdAt' | 'updatedAt'>

export type SavePromptRequest = PromptImportDraft
```

`PromptImportDraft` 是“预览可保存”的结构。renderer 不需要知道抓取细节，只展示这个 draft。

## 数据库设计

在 `apps/desktop/electron/database/schema.sql` 新增：

```sql
CREATE TABLE IF NOT EXISTS prompts (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  content TEXT NOT NULL,
  description TEXT,
  source_site TEXT NOT NULL,
  source_url TEXT,
  source_author TEXT,
  original_source_url TEXT,
  original_language TEXT,
  categories_json TEXT NOT NULL DEFAULT '[]',
  preview_images_json TEXT NOT NULL DEFAULT '[]',
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_prompts_updated_at
  ON prompts(updated_at DESC);

CREATE UNIQUE INDEX IF NOT EXISTS idx_prompts_source_url
  ON prompts(source_url)
  WHERE source_url IS NOT NULL;
```

字段说明：

- `content` 保存完整 prompt。
- `description` 保存页面说明。
- `source_site` 第一版主要是 `youmind`。
- `source_url` 保存 YouMind 详情页 URL。
- `original_source_url` 保存页面中的原始来源链接，例如 x.com。
- `categories_json` 和 `preview_images_json` 使用 JSON 字符串保存数组，符合当前项目已有 `references_json` 的做法。

如果重复导入同一个 `source_url`，建议 v1 使用 upsert：

```txt
source_url 已存在
  -> 更新标题、内容、元数据和 updated_at
source_url 不存在
  -> 新建记录
```

这样用户重复导入同一条提示词不会产生重复数据。

## IPC 设计

### shared channel

在 `packages/shared/src/ipc.ts` 新增：

```ts
prompt: {
  previewImport: 'prompt:preview-import',
  save: 'prompt:save',
  list: 'prompt:list',
}
```

### ElectronApi

在 `packages/shared/src/api.ts` 新增：

```ts
previewPromptImport: (url: string) => Promise<PromptImportDraft>
savePrompt: (request: SavePromptRequest) => Promise<PromptRecord>
listPrompts: () => Promise<PromptRecord[]>
```

### preload

在 `apps/desktop/electron/preload.ts` 暴露同名方法：

```ts
previewPromptImport: (url: string) => {
  return ipcRenderer.invoke(IPC_CHANNELS.prompt.previewImport, url)
},
savePrompt: (request: SavePromptRequest) => {
  return ipcRenderer.invoke(IPC_CHANNELS.prompt.save, request)
},
listPrompts: () => {
  return ipcRenderer.invoke(IPC_CHANNELS.prompt.list)
},
```

## Main Process 设计

### PromptController

新增 `apps/desktop/electron/controllers/promptController.ts`。

职责：

- 注册 prompt 相关 IPC handler。
- 对输入做基础类型检查。
- 将抓取交给 `PromptImportService`。
- 将保存和列表读取交给 `PromptService`。

建议 handler：

```txt
prompt:preview-import(url)
prompt:save(request)
prompt:list()
```

### PromptImportService

新增 `apps/desktop/electron/services/promptImportService.ts`。

职责：

- 校验 URL。
- 只允许 YouMind prompt 详情页。
- fetch HTML。
- 解析页面内容为 `PromptImportDraft`。
- 在解析失败时返回可理解的错误信息。

URL 限制建议：

```txt
hostname 必须是 youmind.com
pathname 必须包含 /prompts/
```

YouMind 解析策略：

- `h1` 作为标题。
- “提示词”区域后的正文作为 `content`。
- 标题下方说明作为 `description`。
- 作者区域解析为 `sourceAuthor`。
- “查看原始来源”链接解析为 `originalSourceUrl`。
- “发布时间”解析为文本或时间戳。
- “原始语言”解析为 `originalLanguage`。
- “分类”后的链接文本解析为 `categories`。
- 页面图片解析为 `previewImages`。

第一版可以优先使用 HTML 文本和 DOM 选择器解析。如果 YouMind 是静态可读页面，这种方式足够简单。若后续发现页面依赖动态数据，再考虑解析 Next.js/RSC 数据或内部接口。

### PromptService

新增 `apps/desktop/electron/services/promptService.ts`。

职责：

- 校验保存请求。
- 生成 `id`。
- 将数组字段序列化为 JSON。
- 写入 `prompts` 表。
- 查询并反序列化为 `PromptRecord[]`。

基础校验：

- `title.trim()` 不能为空。
- `content.trim()` 不能为空。
- `sourceUrl` 如果存在，必须是合法 URL。
- `categories` 和 `previewImages` 必须限制为数组。
- 字符串字段入库前 trim。

## Renderer 设计

替换 `apps/desktop/src/features/PromptManagement/index.tsx` 占位页。

页面状态：

```ts
const [importUrl, setImportUrl] = useState('')
const [importDraft, setImportDraft] = useState<PromptImportDraft | null>(null)
const [prompts, setPrompts] = useState<PromptRecord[]>([])
const [loading, setLoading] = useState(false)
const [saving, setSaving] = useState(false)
const [error, setError] = useState<string | null>(null)
```

UI 分区：

- 导入栏：URL input、读取按钮。
- 导入预览：标题、正文、描述、分类、来源、预览图、保存按钮。
- 已保存列表：记录标题、摘要、分类、来源、更新时间。

第一版不需要完整编辑器，但可以允许用户保存前看到完整 prompt，避免误存。

## 错误处理

需要明确给用户反馈：

- URL 为空：请输入提示词详情页链接。
- URL 不合法：链接格式不正确。
- 非 YouMind prompt URL：目前只支持 YouMind 提示词详情页。
- 网络失败：无法读取网页，请稍后重试。
- 页面结构不匹配：没有解析到提示词内容。
- 保存失败：保存提示词失败。

主进程错误信息可以直接抛出中文 `Error`，renderer 捕获后展示。

## 后续扩展

v1 完成后可以继续扩展：

- 手动创建提示词。
- 编辑已保存提示词。
- 删除提示词。
- 搜索和分类筛选。
- 一键复制 prompt。
- 一键填入创作页输入框。
- 本地缓存预览图。
- 从 YouMind 列表页批量导入。
- 抽象多来源导入器，例如 `PromptImporter` interface。

## 验证用例

基础导入：

```txt
输入 YouMind prompt 详情页 URL
点击读取提示词
看到标题、prompt、分类、来源和预览图
点击保存
列表出现该提示词
重启应用后该提示词仍存在
```

重复导入：

```txt
导入同一个 source_url 两次
数据库只有一条记录
第二次导入更新 updated_at
```

错误路径：

```txt
输入空 URL
输入非 URL 文本
输入非 youmind.com URL
输入 youmind.com 但不是 /prompts/ 的 URL
断网或 fetch 失败
```

这些场景都应有明确错误提示，不应让页面静默失败。
