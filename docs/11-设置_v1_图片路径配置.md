# 图片路径配置

## 概述

允许用户自定义图片库的目录/文件命名规则，通过模板字符串控制图片存储路径结构。

## 模板变量

| 变量 | 说明 | 示例值 |
|------|------|--------|
| `{YYYY}` | 创建年份（4位） | 2026 |
| `{MM}` | 创建月份（2位补零） | 05 |
| `{DD}` | 创建日期（2位补零） | 12 |
| `{jobId}` | 任务 ID | abc123 |
| `{index}` | 图片序号（4位补零） | 0001 |

## 默认模板

```
{YYYY}-{MM}/{jobId}/{index}
```

生成路径示例：`2026-05/abc123/0001.png`

## 用户自定义示例

| 模板 | 生成路径 |
|------|----------|
| `{YYYY}-{MM}/{jobId}/{index}` | `2026-05/abc123/0001.png` |
| `{YYYY}-{MM}/{jobId}_{index}` | `2026-05/abc123_0001.png` |
| `{YYYY}/{MM}/{DD}/{jobId}/{index}` | `2026/05/12/abc123/0001.png` |
| `{YYYY}-{MM}-{DD}/{index}` | `2026-05-12/0001.png` |

## 最终路径组成

```
图片库根目录 / 模板渲染结果 + 源文件扩展名
```

扩展名由源文件自动决定（如 `.png`、`.jpg`），不纳入模板。

## 模板校验规则

1. 必须包含 `{index}` — 确保同任务多张图片不冲突
2. 禁止 `..` — 防止路径穿越
3. 禁止以 `/` 开头 — 不允许绝对路径
4. 仅允许的字符：模板变量、字母、数字、`-`、`_`、`/`、`.`
5. 不允许连续 `/`（如 `{YYYY}//`）
6. 渲染后路径长度不超过 200 字符

## 冲突处理

无论模板如何配置，目标文件已存在时自动追加版本号：

```
0001.png → 0001-2.png → 0001-3.png → ...
```

## 改动范围

1. **settingsService** — 新增 `imagePathTemplate` 配置项，默认值 `{YYYY}-{MM}/{jobId}/{index}`
2. **imageLibraryService.createAvailableTargetPath** — 用模板渲染替代硬编码拼接
3. **新增 templateValidator** — 校验用户输入的模板合法性，不合法时回退默认值并提示
4. **设置界面** — 新增输入框，带实时预览（显示当前模板渲染后的示例路径）
